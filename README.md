# Excel Financial Analysis & Ratio Modeling

Two Excel labs from Bentley University's *Data Analytics for Accountants* course (AC 770), working with a large financial facts data set (1,000+ rows by 34 columns).

**What I built**
- **Lab 1A:** structured the raw financial data and summarized it with PivotTables.
- **Lab 1B:** a multi-sheet ratio model covering **Profitability, Activity, Financing, Liquidity and DuPont** analysis, with a Summary sheet tying the results together.

**Skills shown:** PivotTables, formulas across large data sets, financial statement ratio analysis, DuPont decomposition, building a clean multi-tab model.

*Data files and course answer keys are not included in this repository.*
